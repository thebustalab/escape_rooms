Find the real-life analog

Before designing anything, ask: where in ordinary life do people already perform, by hand, what this chapter's code does? Name the everyday act behind the technique's verbs — group_by/summarise is sorting things into piles by a shared trait and reading one number off each pile (a naturalist tallying a transect); a filter is walking a shelf and pulling only what matches; clustering is sorting a mixed heap into "these belong together."

For computation-heavy techniques, look especially for the case where the computation is already done and a person only has to RECOGNISE it — reading which grouping produced a display, spotting the odd one out, matching a shape. That recognition-not-computation move usually makes the sharpest, fairest escape (the unlabelled echo of the boss technique). Let this analog seed the world, the puzzles, and above all the escape — then move on to Step 1. (Worked example: wrangling/trees — the monorail cars are already grouped-and-summarised, and the escape is recognising which grouping each car used.)

8

Sounds

Ask Claude to pull candidates per room (from freesound) into the scenario's _scratch/audio/ pool — two clear ambient loops + two intermittent one-shots each — saying what each should evoke (e.g. "elevator motor hum" + "break-room fridge drone" for beds; "distant beep", "occasional clunk" for the intermittent ones). They appear below per room; audition each with its play button and hit Add to layer it in. A room can hold several layers that play together, each with a mode: loop (a continuous bed — the seam is equal-power crossfaded by the crossfade s overlap, default 4s) or interval (replays after a random gap — a one-shot like a distant beep). Set volume/delay/duck per layer, then Save sounds. Sounds play while you're in the room and are not muted by the music toggle. Do the music first, then let the agent wire every room's sfx + solve stings and auto-balance them to perceived-loudness under the music; fine-tune by ear in ▶ Test play.
